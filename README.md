# French news title generation

This repositery contains the code used to participate to a Kaggle challenge on generating titles for French press articles, which involved comparing pretrained French summarization models, text-reduction strategies, and fine-tuning to maximize ROUGE-L scores.

It does not include the weights of the summarization models used, nor the Kaggle dataset [orange sum](https://www.kaggle.com/datasets/abdellatifabdellatif/orange-sum).
